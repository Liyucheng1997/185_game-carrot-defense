# 🥕 保卫萝卜大作战 v2

纯 HTML5 Canvas 手绘的塔防小游戏，零依赖、零素材文件——所有可爱造型（会哭会笑的萝卜、眨眼睛的怪物、带表情的炮塔）都是代码实时绘制的。

## 怎么玩

直接双击 `index.html` 用浏览器打开即可。

- 🗺️ **选地图 / 难度**：开始界面选 4 张地图之一、4 档难度，可勾选 ♾️ 无尽模式
- 🖱️ **点击空地**：打开环形建造菜单，选一种炮塔（悬停可预览攻击范围和说明）
- 🖱️ **点击已有炮塔**：升级（最高 3 级）或出售（返还 70%）
- 🪨 **障碍物**：炮塔没有怪打时会自动拆地图上的树/石头/宝箱，拆掉得金币并解锁地块，宝箱还可能回 1 血
- 🔥❄️💚 **主动技能**（快捷键 1/2/3）：陨石砸落范围伤害 · 全场冻结 3 秒（幽灵也定住） · 花 120 金币修复 1 血
- 🚀 **提前召唤**：准备阶段点顶部按钮提前出怪，按剩余秒数奖励金币；顶部会预告下一波兵种
- 🎁 **礼物盒**：地图上不定时刷新，消失前点击它白捡一笔金币
- ⏩ 支持 x1/x2/x3 加速，空格暂停；最佳纪录保存在浏览器本地

## 四张地图

| 地图 | 波数 | 特点 |
|------|------|------|
| 🌳 青青草原 | 20 | 单入口绕山路，入门友好 |
| 🌵 沙漠绿洲 | 25 | 超长蛇形路，考验火力布局 |
| ❄️ 冰雪王国 | 30 | 双入口，南边小路直通萝卜 |
| 🌋 熔岩地狱 | 30 | 双入口 + 短路，怪物更凶 |

难度：轻松 / 普通 / 困难 / 噩梦，分别影响怪物血量、速度、数量、掉落金币和准备时间。无尽模式下波次不封顶，每 10 波加一只终极魔王。

## 九种炮塔

| 炮塔 | 定位 |
|------|------|
| 萝卜瓶 | 便宜、攻速快的单体输出 |
| 小风扇 | 飞出扇叶，穿透一整排怪物 |
| 雪花球 | 冰冻脉冲，范围减速（幽灵免疫减速！） |
| 小火箭 | 范围爆炸，克制抱团 |
| 电击球 | 连锁闪电，一次电中最多 6 只 |
| 毒蘑菇 | 毒孢子持续掉血，无视护甲 |
| 星星炮 | 超远射程狙击，高伤害可暴击 |
| 大磁铁 | 周期性把周围怪物推回去（Boss 只推一点点） |
| 太阳花 | 不攻击，定时产出金币 |

# 🥕 保卫萝卜大作战

纯 HTML5 Canvas 手绘的塔防小游戏，零依赖、零素材文件——所有可爱造型（会哭会笑的萝卜、眨眼睛的怪物、带表情的炮塔）都是代码实时绘制的。

## 怎么玩

直接双击 `index.html` 用浏览器打开即可。

- 🖱️ **点击空地**：打开环形建造菜单，选一种炮塔（悬停可预览攻击范围和说明）
- 🖱️ **点击已有炮塔**：升级（最高 3 级）或出售（返还 70%）
- 🚀 **提前召唤**：准备阶段点顶部按钮提前出怪，按剩余秒数奖励金币
- 🎁 **礼物盒**：地图上不定时刷新，消失前点击它白捡一笔金币
- 🥕 **点萝卜**：它会开心地蹦一下～
- 守住 **20 波**（每 5 波一个 Boss）就胜利，按剩余血量结算星级

## 五种炮塔

| 炮塔 | 定位 |
|------|------|
| 萝卜瓶 | 便宜、攻速快的单体输出 |
| 小风扇 | 飞出扇叶，穿透一整排怪物 |
| 雪花球 | 冰冻脉冲，范围减速（幽灵免疫减速！） |
| 小火箭 | 范围爆炸，克制抱团 |
| 太阳花 | 不攻击，定时产出金币 |

## 五种怪物

豆豆怪（普通）、蝙蝠仔（飞得快）、胖胖猪（血厚）、小幽灵（免疫减速）、大魔王（Boss，咬萝卜一口掉 3 血）。

## 文件结构

```
index.html   页面骨架 + HUD
style.css    界面样式
game.js      全部游戏逻辑与手绘渲染（单文件）
```
